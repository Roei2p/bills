# החזרי קבלות

מערכת אישית לקבלת החזרים על הוצאות רפואיות מהביטוח המשלים של קופת החולים ומביטוח בריאות פרטי.

1. מצלמים קבלה.
2. המערכת קוראת אותה, בוחרת לאן להגיש ומכינה את הפרטים לטופס התביעה.
3. מגישים באתר המבטח, והמערכת עוקבת עד שהכסף חוזר, ומציעה בקשת השלמה לביטוח הפרטי על ההפרש.

הנתונים נשמרים רק בדפדפן במכשיר שלכם. קריאת קבלות בחינם: דרך [OmniRoute](https://www.omniroute.online/) שרץ במחשב שלכם (מודל `auto/vision:free`), ואם הוא לא זמין, בתוך הדפדפן (Tesseract).

חיבור OmniRoute, פעם אחת: פותחים את `https://bills.rlapp.net/app/#omni=<מפתח OmniRoute>` (או `#omni` בלי מפתח). כתובת אחרת: `#omni=<מפתח>&url=<כתובת>`.

אתר: https://roei2p.github.io/bills/
