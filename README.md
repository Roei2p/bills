# החזרי קבלות

מערכת אישית לקבלת החזרים על הוצאות רפואיות מהביטוח המשלים של קופת החולים ומביטוח בריאות פרטי.

1. מצלמים קבלה.
2. המערכת קוראת אותה, בוחרת לאן להגיש ומכינה את הפרטים לטופס התביעה.
3. מגישים באתר המבטח, והמערכת עוקבת עד שהכסף חוזר, ומציעה בקשת השלמה לביטוח הפרטי על ההפרש.

הנתונים נשמרים רק בדפדפן במכשיר שלכם. קריאת קבלות היא בחינם ורצה בתוך הדפדפן (Tesseract), בלי מפתח. אפשרויות רשות בהגדרות: מסלול החינם של NVIDIA דרך שרת פרטי (ראו [proxy](proxy/README.md)), או מפתח Claude בתשלום.
